# 사업 개요

## 요약

| 항목 | 내용 |
|------|------|
| 사업명 | AI 기반 채용 프로세스 자동화 및 지원자 통합 관리 플랫폼 |
| 시스템명 | Arda (Eval-ATS) |
| 개발 기간 | 2026년 8월 20일 ~ 2026년 10월 27일 (10주, 5스프린트) |
| 개발 인원 | 5명 |
| 개발 방법론 | 애자일 스크럼 (2주 단위 스프린트) |

---

## 사업 목적

채용 과정에서 발생하는 반복 업무를 자동화하고, 흩어진 지원자 정보를 하나의 플랫폼으로 통합하여 채용 담당자의 업무 효율성을 높인다.

채용담당자가 공고를 올리고, 지원자가 외부 링크로 지원서·이력서를 제출하면, 담당자·면접관이 칸반 보드에서 단계별로 심사·평가하고, 단계 변경 시 지원자에게 메일이 자동 발송된다. 흩어져 있던 채용 과정(접수 → 서류 검토 → 면접 → 합불 통보)을 하나의 시스템으로 묶고, 모든 단계 이동에 이력과 평가 기록이 남게 한다.

---

## 주요 사업 내용

| 영역 | 내용 |
|------|------|
| 채용 프로세스 자동화 | 칸반 보드 기반 단계 관리, 단계 변경 시 자동 메일 발송, 단계 이력 기록 |
| AI 기반 이력서 분석 | PDF/DOCX 이력서 구조화 추출, RAG 기반 질의응답 |
| 지원자 통합 관리 | 지원자 CRUD, 검색·필터, 면접관 배정, 평가 기록, 공고별 지원 현황 |
| 공개 지원 시스템 | 외부 공개 링크를 통한 지원서 접수, 이력서 S3 직접 업로드 |
| 인증·권한 체계 | JWT 인증, 역할 3종(관리자 / 채용담당자 / 면접관) 기반 접근 제어 |

## 기대 효과

| 구분 | 기대 효과 |
|------|----------|
| 업무 효율 | 채용 단계 전환·알림을 자동화하여 담당자 반복 업무 감소 |
| 정보 통합 | 지원자 정보·이력서·평가·이력을 단일 시스템에서 조회 |
| 의사결정 지원 | AI 이력서 파싱 및 RAG 질의응답으로 지원자 정보 신속 파악 |
| 투명성 확보 | 모든 단계 이동과 평가에 이력이 남아 채용 과정의 투명성 보장 |
| 접근성 향상 | 모바일 대응 UI, 외부 공개 지원 링크로 시간·장소 제약 없이 지원 가능 |
