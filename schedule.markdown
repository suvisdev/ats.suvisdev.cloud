## 주간 리듬

| 요일 | 활동 |
|------|------|
| 월 | 오너별 주간 계획 수립 — 지난주 점검 → 이번 주 큐 → 게이트 역산 → 로드맵 갱신 |
| 상시 | 자기 큐 소화, main 직접 push(push 전 실행·테스트 필수), 칸반 사이트 갱신 |
| 금 | 주간 다이제스트 — 그 주 커밋 요약 + 칸반 done 열 (검수가 아니라 파악용) |
| 게이트 주 | 실측 기반 판정 — 문서 근거가 아니라 배포본 대조·관통 테스트 |

- 주차 계획 원문은 고치지 않고 하위 절로 덧붙인다 — **한 주에 하위 절이 3개를 넘으면 계획이 틀렸다는 신호**로 다음 주 첫 줄에 원인을 기록한다
- 승인 대기 없이 main에 바로 반영하는 방식(트렁크 개발)으로 속도를 얻고, 자동 검사(CI)가 안전망 역할을 한다. 스키마·API·공용 문서처럼 남에게 영향을 주는 변경은 반영 후 바로 공지하고, 이견이 있으면 해당 커밋을 되돌리는 것(revert)이 기본값이다
