## 위험 관리 방안

| 위험 요소 | 영향 | 대응 방안 |
|----------|------|----------|
| 일정 지연 | 스프린트 목표 미달성 | 기능 우선순위에 따라 범위 조정, 미결 항목은 다음 스프린트로 이월 |
| AI 기능 범위 초과 | 핵심 기능 개발 시간 부족 | AI 기능은 여유 시 범위로 분류, 합불 확정은 사람이 하는 원칙 유지 |
| 팀원 간 기술 격차 | 특정 파트 병목 | PR 리뷰를 통한 지식 공유, 페어 프로그래밍 적용 |
| AWS 비용 초과 | 프로젝트 예산 초과 | Aurora Serverless v2 유휴 시 자동 일시정지, S3 수명주기 정책 적용 |
| 개인정보 유출 | 법적 리스크 | 이력서 S3 SSE 암호화, 개인정보 AES-256 암호화, IAM 최소 권한 원칙 |
